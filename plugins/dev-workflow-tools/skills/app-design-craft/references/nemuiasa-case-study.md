# 実例集：nemuiasa apps（@nemuiasapp）

原則が現実にどう結実するかの参照点。レビュー/設計で「優れた引き算の具体例」を引きたいときに読む。
2026年6月にX(Twitter)アカウントのプロフィール・固定ツイート・メディアを徹底調査して作成。

## どんな作り手か

- **nemuiasa apps**（@nemuiasapp）／開発者 白水 桃花（@nemuiasaa）。個人開発スタジオ。
- 自己紹介：**「余白を大切にした、静かでやわらかなデザイン。日常にそっと寄り添うアプリを開発しています。」**
- 公開アプリ：**relight（主力・ライブ/フェス記録）／ hibi（日記・習慣）／ ondot timer（タイマー）／ ornett**。基本無料・広告なし。
- この自己紹介の一文が、全プロダクト・全接点で文字通り実装されているのが最大の学び。**コンセプトを言葉にし、それを隅々まで守りきっている。**

## 観察された具体（6レンズで整理）

### Restraint（抑制）
- ベースはオフホワイト/クリーム＋ほぼ黒。差し色は**アプリごとに1色だけ**（ondot=赤、ornett=紫）。
- relight の UI は基本モノクロ。背景に淡いパステルグラデを"白に溶ける程度"だけ。
- 情報を極限まで削いだ「🕐 1.0 審査中」だけのティーザーカード。

### Hierarchy & Focus（階層と焦点）
- プロモは1枚＝1メッセージ：「ライブの記憶を、美しく残す。」「締切も当落も、relightが覚えてる。」「数字で振り返る」。
- カウントダウン「15 DAYS」、統計の「LIVE 4 / venues 4」など**数字を特大**に＝感情のフック。
- イベント詳細は cover→日付→黒ピル強調→タイトル→アーティスト→メタ、と視線が一本道。

### Rhythm & Spacing（余白とリズム）
- 余白最優先。要素間・行間・タップ領域が広くゆったり。
- 白い角丸カード（半径大きめ＋極薄シャドウ）で要素をグルーピング。iOSのグループ化リストを上品に拡張。

### Voice & Copy（言葉）
- 機能でなく体験を語る：「relightが覚えてる」「美しく残す」。
- ライブ文化の常套句**"参戦"をあえて使わないポリシー**。流行語に媚びない柔らかな日本語。
- FAQ・Tips・ロードマップを丁寧語で発信し、レビューに温かく返信。

### Coherence（一貫性／世界観）
- ロゴ（小文字n）→4アプリの白角丸アイコン→プロモ→アプリ内UI→**App Storeレビュー紹介画像まで**、同じ"静かで柔らかい"様式が貫通。
- 社会的証明（レビュー）すら、白角丸カード＋大きな「5」＋星分布、という自社様式で再描画。
- アプリ名はすべて小文字ワードマーク（relight 等）。

### Craft（仕上げ）
- メタ情報は細い線アイコン（📍会場・🎫¥18,000・🏷イープラス）で軽やかに。
- hibi の言語設定は「( 言語 )」を括弧＋字間スペース＋明朝系で"静けさ・余韻"を演出。
- ステータス遷移（未応募→当落待ち→入金待ち→確保済み）まで状態を設計。

## 一行で

**「色を1つに、余白を最大に、言葉を誠実に。引き算で世界観を貫けば、静けさそのものがブランドになる。」**

## 注意（一般化のために）

これは「モノトーン＋余白」という**ひとつの解**であって、唯一解ではない。学ぶべきは見た目そのものより、**(1) コンセプトを一文に凝縮し (2) それを全接点で1ミリも妥協せず貫いた**という姿勢。賑やかなアプリでも、同じ「役割を持って置く・世界観を貫く」を適用すれば優れたデザインになる。
