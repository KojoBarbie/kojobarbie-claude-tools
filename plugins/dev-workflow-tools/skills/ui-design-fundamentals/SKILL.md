# UI Design Fundamentals

Adham Dannaway氏による「14 Logic-Driven UI Design Tips」に基づくUIデザインガイド。

**Reference**: https://www.adhamdannaway.com/blog/ui-design/ui-design-tips-14

---

## 1. Space Elements Based on Relationship

**要素間の関係性に基づいてスペースを調整する**

関連性の高い要素は近くに、関連性の低い要素は離して配置する。これにより視覚的なグループ化が生まれ、ユーザーが情報の構造を直感的に理解できる。

**実装方法**: 8ポイントグリッドシステムを採用し、事前定義されたスペーシングオプション（8pt, 16pt, 24pt, 32pt, 48pt...）を比例的に使用する。

---

## 2. Interface Elements Need 3:1 Contrast

**UI要素には最低3:1のコントラスト比が必要**

ボタンやインタラクティブなコンポーネントは、WCAG 2.1 Level AA基準に準拠し、最低3:1のコントラスト比を確保する必要がある。これにより、低視力のユーザーでも要素を識別できる。

---

## 3. Single Primary Button Per Screen

**最も重要なアクションには1つのプライマリボタンを使用する**

1画面に複数のプライマリボタンがあると、ユーザーは次に何をすべきか混乱する。最も重要なアクションを1つに絞り、それをプライマリボタンとして目立たせる。

---

## 4. Buttons Require Sufficient Target Size

**ボタンには十分なターゲットサイズが必要**

最小ボタンサイズは**48pt × 48pt**とし、ボタン間には**最低8pt**の間隔を設ける。これにより誤タップを防ぎ、特に運動機能に制限のあるユーザーのアクセシビリティを向上させる。

---

## 5. Visible Important Content

**重要なコンテンツは常に見える状態にする**

スペースに余裕がある場合、重要なアクションをインタラクティブメニューの背後に隠さない。隠れた機能はユーザーに見落とされる可能性がある。

---

## 6. Decrease Letter Spacing for Large Text

**大きなテキストはレタースペーシングを狭める**

見出しなどの大きなテキストは、レタースペーシング（文字間隔）を縮めると美しく見える。特に本文用にデザインされたテキストタイプの書体で効果的。

---

## 7. Don't Rely on Color Alone

**色だけをインジケーターとして頼らない**

色の変更に加えて、下線や塗りつぶしなどの追加の視覚的手がかりを使用する。これにより色覚多様性のあるユーザーも情報を正しく認識できる。

---

## 8. Minimize Multiple Alignments

**複数のアラインメントを最小限に抑える**

インターフェースセクション全体で1つのアラインメント（できれば左揃え）を維持する。複数のアラインメントは認知負荷を増加させ、視覚的な複雑さを生み出す。

---

## 9. Text Requires 4.5:1 Contrast

**テキストには4.5:1のコントラスト比が必要**

WCAG準拠のため：
- **小さいテキスト**（18px以下）: 最低**4.5:1**のコントラスト比
- **大きいテキスト**（18px太字以上、または24px以上の通常テキスト）: 最低**3:1**のコントラスト比

---

## 10. Remove Unnecessary Containers

**不要なコンテナを削除してインターフェースをシンプルにする**

近接性、類似性、配置などの他のグループ化方法ですでに要素が効果的に整理されている場合、コンテナ（枠線や背景）の削除を検討する。

---

## 11. Use Regular and Bold Font Weights Only

**フォントウェイトはRegularとBoldのみを使用する**

フォントの太さをRegularとBold（またはSemiBold）の2種類に制限することで、視覚的なノイズを減らし、デザインシステム全体で一貫した実装を確保できる。

---

## 12. Maintain Design Consistency

**デザインの一貫性を保つ**

類似した要素は、製品内でも業界標準全体でも、同じように見え、同じように機能する必要がある。角丸の半径などの細部の一貫性が、まとまりのあるビジュアル言語を生み出す。

---

## 13. Don't Confuse Minimalism with Simplicity

**ミニマリズムをシンプルさと混同しない**

詳細を削りすぎると、ユーザビリティが損なわれる可能性がある。ミニマルなデザインが必ずしもシンプルで理解しやすいとは限らない。必要な情報は残すこと。

---

## 14. Balance Icon and Text Pairs

**アイコンとテキストのペアをバランスよく配置する**

アイコンと隣接するテキストが同様の視覚的な存在感を持つように、色と太さを調整する。これによりバランスのとれた、まとまりのあるコンポーネントが生まれる。

## Quick Reference Table

| カテゴリ | 基準値 |
|---------|--------|
| スペーシング | 8ptグリッドシステム |
| ボタン最小サイズ | 48×48pt |
| ボタン間隔 | 8pt以上 |
| UI要素コントラスト | 3:1以上 |
| 小テキストコントラスト（≤18px） | 4.5:1以上 |
| 大テキストコントラスト（>18px bold / >24px） | 3:1以上 |
| フォントウェイト | 2種類まで（Regular + Bold） |

## UI Review Checklist

UIレビュー時に確認すべき項目：

### Spacing & Layout
- [ ] スペーシングは8ptグリッドに準拠しているか
- [ ] 関連要素は近く、無関係な要素は離れているか
- [ ] アラインメントは統一されているか（できれば左揃え）
- [ ] 不要なコンテナ（枠線・背景）はないか

### Buttons & Interactive Elements
- [ ] プライマリボタンは1画面に1つか
- [ ] ボタンのタップ領域は48×48pt以上確保されているか
- [ ] ボタン間は8pt以上の間隔があるか
- [ ] 重要機能がメニューに隠れていないか

### Accessibility
- [ ] UI要素のコントラスト比は3:1以上か
- [ ] 小テキストのコントラスト比は4.5:1以上か
- [ ] 大テキストのコントラスト比は3:1以上か
- [ ] 色以外の視覚的手がかり（下線、アイコン等）があるか

### Typography
- [ ] フォントウェイトは2種類以内か
- [ ] 大きな見出しのレタースペーシングは適切に狭められているか

### Consistency
- [ ] 類似要素の見た目と動作は統一されているか
- [ ] 角丸、色、シャドウなどの細部は一貫しているか
- [ ] アイコンとテキストの視覚的バランスはとれているか

### Design Philosophy
- [ ] ミニマルにしすぎて必要な情報が欠けていないか
- [ ] ユーザーが次のアクションを理解できるか
